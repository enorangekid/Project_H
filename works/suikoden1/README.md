## 작품 안내

게임 쪽 도구는 이 저장소가 아니라 `C:\Games\Suikoden I and II HD Remaster\mod\tools\` 에 있습니다. 데이터는 거기서 만들어 이 작품 폴더에 씁니다.

- 씬 = 게임의 지역 코드(대사 번호 앞 4자리, 예: `1011` 궁전, `1002` 그레그민스터·맥돌 저택). 단계 = 장면(음성 폴더 구분과 같음, 1011·1002만 나눔).

- `english` = 게임의 공식 영어. `recordingScript` = 녹음(ElevenLabs)용 대본, 주인공 이름은 `티르`. `voice` ✓ = `C:\AI\voice\dub\완성`의 확정본이 게임에 들어가 있음. `speaker`는 게임 데이터에 없어서 확인한 장면만 채워져 있습니다.
- 음성 폴더: `work.json`의 `voiceDir` = `works/suikoden1/voice/` → `mod\voice\_game` 으로 연결한 바로가기(junction, Git 제외).
- 명령 (`mod\tools` 에서):
  ```bash
  node projecth.js export   # 게임 대사 → 이 작품 (화자·메모·프롬프트·검수 표시·직접 고친 녹음 대본은 유지)
  node projecth.js import   # 여기서 고친 korean → mod/dialogue_fix/edits.json

  ```
  대사 수정 흐름: `scene.js --work suikoden1 set …` → `projecth.js import` → `name_fix.js build/install` → `projecth.js export`.
- 프롬프트 분류 탭은 이 작품 전용(`data/prompts.js`의 `groups`): **캐릭터 톤 / 감정 / 말투·호흡 / 상황**. 공식·화자별 기본 톤·적용 현황은 아래 `프롬프트 제작 설계`에 있습니다. 템플릿은 ElevenLabs 지시문(`[angry]` 형식) 초안이라 사용자와 함께 다듬을 것.
- 이 작품은 페이지를 열면 화자 필터가 **`화자 있음`**으로 시작합니다(`work.json`의 `"speakerFilter": "set"`, 바꾼 뒤 `node tools/work.js sync`). 화자가 아직 없는 씬은 빈 표로 보이니, 전부 보려면 필터를 `전체 화자`로 바꾸세요.
- CG 메뉴와 `일 ▶`(일본어 원본 음성) 버튼은 이 작품에서 숨깁니다(`work.json`의 `"cg": false`, `"originalVoice": false`). 저장 서버의 CG·일본어 원본 폴더는 공용 설정이라 서희 자료가 섞여 보였기 때문입니다.

### 화자 확인 작업 (게임 내 확인 필요 — 미착수, 2026-11-13)

- **배경**: `speaker`는 게임 데이터에 없어서 지금까지 전부 대사 내용·말투·영어 원문으로 **추정**했습니다(근거가 없는 줄은 비우거나 `화자 불확실: …` 메모). 1031 트란 성은 동료 수십 명이 각자 하는 일상 대사가 약 700행이라 대사 안에 이름이 없어 추정 자체가 어려워 **1단계(연출 구간)까지만 하고 중단**했습니다. 녹음하기 전에 **"이 대사의 주인이 누구인지" 게임 안에서 확인하는 작업**이 먼저 필요합니다.
- **확인이 필요한 줄**(2026-11-13 기준): `화자 불확실` 메모 **150줄**(1003 6 · 1004 51 · 1005 9 · 1006 20 · 1027 5 · 1028 6 · 1031 44 · 1034 6 · 1103 3), `화자 추정` 메모 **243줄**(1003·1005·1103 — 1011·1002는 화자를 어떻게 정했는지 기록이 없음), 1031의 나머지 블록(`02xxx` 2081번 이후·`03xxx`·`17xxx`·`27xxx`~`30xxx`·`42xxx`·`52xxx`, 사실상 전부 미입력), 아직 손대지 않은 씬 전부(1029·1007·1032·1052 이후).
- **확인 방법(우선순위)**: ① 집 PC의 `mod\환상수호전1_대사.xlsx`(게임에서 처음 뽑은 엑셀)에 화자·인물 열이 있는지 확인 — 있으면 그 값으로 일괄 반영·검증. ② 게임 데이터(TextAsset `text_gsd1_ja` 번들과 이벤트 스크립트)에 대사 ID ↔ 말하는 인물(초상화·이름창) 정보가 있는지 확인(`mod\tools\dialogue_export.js` 참고). ③ 없으면 게임을 실행해 대사 ID(`<대사번호>_<창번호>`)를 띄워 말하는 캐릭터를 직접 확인(`화자 불확실` 메모 줄부터). ④ 동료 일상 대사(1031)는 "동료 이름 → 대사 ID" 표를 한 번 만들면 한꺼번에 처리 가능.
- **반영 방법**: 확인한 줄은 `scene.js --work suikoden1 set <씬ID> patch.json --note "화자 확인"`으로 `speaker`를 넣고, `memo`의 `화자 불확실/추정` 문구는 지우며, 화자가 바뀐 줄은 `prompt`도 위 `화자별 기본 캐릭터 톤` 표에 맞춰 다시 적용합니다. 메모로 줄 찾기: `node tools/scene.js --work suikoden1 get <씬ID> --search "화자 불확실" --fields id,speaker,korean,memo --tsv`.
- **재개 조건**: 확인 방법(위 ①~③)이 정해지기 전에는 새 씬의 화자 정리를 이어가지 않습니다. 직책·묘사형 화자와 일상 대사 인물을 **실제로 더빙할지**도 이 확인이 끝난 뒤 사용자가 다시 정합니다.

### 프롬프트 제작 설계 (ElevenLabs, 2026-11-13)

녹음은 **ElevenLabs**로 하고, 프롬프트는 `[a, b, c]` 형식의 영어 태그입니다. 페이지에서 템플릿을 여러 개 켜면 **누른 순서대로** 이어 붙습니다. (새가족의 `프롬프트 제작 설계`와 같은 틀이지만, 환수는 인물이 너무 많아 인물별 태그를 두지 않는 점이 다릅니다.)

- **구조**: 분류 탭 4개(`일반/행위` 구분 탭은 쓰지 않음) — `캐릭터 톤`(11) / `감정`(12) / `말투·호흡`(8) / `상황`(8), 템플릿 39개. 이전에는 38개가 전부 `감정` 탭에 몰려 있었음.
- **공식**: `[캐릭터 톤, 감정, (말투·호흡), (상황)]` 순서. 캐릭터 톤은 화자별 기본 1개(성격이 뚜렷하지 않으면 생략 가능), **감정 하나가 기본**, 필요할 때만 말투·호흡과 상황을 얹음. 합쳐서 2~4개, 같은 태그를 두 번 넣지 않음. 진지한 줄(예: 오데사의 마지막 장면)은 캐릭터 톤을 빼고 감정만 써도 됨.
- **`캐릭터 톤`은 인물 이름별이 아니라 유형(아키타입)**: 등장인물이 매우 많아 인물마다 태그를 만들 수 없으므로 재사용 가능한 11개 유형만 둠 — 황제처럼 위엄 있게, 장군답게 굳건하게, 공손하게, 충직한 하인처럼, 소년답게 밝게, 장난스럽게, 거만하게, 속을 알 수 없게, 무뚝뚝하게, 노련하고 차분하게, 능글맞게(여유로운 한량 `[easygoing, cocky, wry]`). 유형이 부족하면 그때 추가(예: 노인, 아이, 악당). 인물 목소리 자체는 음성 선택 단계에서 정함.
- **화자별 기본 캐릭터 톤(적용한 값)**:
  | 캐릭터 톤 | 화자 |
  |---|---|
  | 장군답게 | 테오, 카심 |
  | 황제처럼 위엄 있게 | 발바롯사 |
  | 속을 알 수 없게 | 윈디(**최종 보스** — 겉은 공손하고 다정하지만 속은 드러내지 않음), 렉크나트, 노승 |
  | 거만하게 | 클레이즈, 카난, 그레이디, 검, 카뮤 |
  | 충직한 하인처럼 | 그레미오 |
  | 소년답게 밝게 | 테드, 유고, 시나, 메그 |
  | 무뚝뚝하게 | 판, 프릭, 바르카스, 험프리, 케스라, 레판토, 야무크, 안지 |
  | 노련하고 차분하게 | 클레오(도련님과 있을 때 `다정함`, 판을 꾸짖을 때 `짜증`, 결단할 때 `결연함`을 얹음), 오데사, 시드니아, 맷슈 |
  | 장난스럽게 | 프치, 루크, 마리 |
  | 능글맞게 | 빅토르, 숨어 있던 노인, 루돈(독차 여관 주인), 오닐, 타이호 |
  | 공손하게 | 산체스, 젠, 모건, 카게, 안토니오, 쥬포, 애플, 시종, 신참 시종, 대신, 수행승 |
- **줄별 감정·말투·상황은 대사 내용과 영어 원문으로 정한 초안**입니다(화자도 추정이라 화자가 틀리면 톤도 같이 틀어짐). 상대 이름을 부르는 줄은 그 상대가 화자가 아니므로 영어 원문으로 다시 확인할 것(예: `1004000133_1`은 영어 원문 "Hear that, Viktor?"로 오데사로 정정, `1103000004_1`은 클레오를 부르는 빅토르의 대사).
- **적용 현황**: 화자가 입력된 10개 씬(1011·1002·1005·1003·1004·1103·1006·1027·1028·1034)의 **화자 줄 전부**에 적용 완료(1006은 화자 121줄·불확실 메모 20줄, 1027은 화자 40줄·메모 5줄, 1028은 화자 116줄·메모 6줄 — 불확실한 줄은 화자·프롬프트 비움, 1034는 화자 9줄·메모 6줄). 그 뒤 **1031 트란 성은 단계별로 진행 중**(1단계: 블록 `00xxx`·`02xxx` 연출 구간 화자 38줄·메모 44줄 완료). 현재 프롬프트가 들어간 줄은 총 806줄. 화자 없는 줄(일반 NPC·선택지·시스템)은 비워 둠. 시종·신참 시종·대신·수행승·숨어 있던 노인 같은 직책·묘사형 화자도 **일단 채워 둠 — 실제로 더빙할지는 화자 정리가 다 끝난 뒤 사용자가 다시 확인**하기로 함.
- **다음**: 화자 확인 작업(환상수호전 항목의 `화자 확인 작업`)을 먼저 하고, 확인 방법이 정해지면 **1031 트란 성 나머지 → 1029 이후 씬**의 화자 정리 → 프롬프트 적용 → 녹음해 보고 조정. 새 씬에도 같은 공식·화자별 기본 톤 표를 따르고, 새 화자는 표에 추가.

### 사용자와 일하는 방식 (환수 작업에서 정해진 것)

- 대사를 보여 달라고 하면 **현재 대사만** 표로 보여 줄 것. 수정 제안은 사용자가 번호를 집어 요청할 때만.
- "2-4-7-14"처럼 말하면 **그 번호들**이지 범위가 아님.
- 장면 대사를 달라고 할 때는 말을 걸어야 나오는 NPC 대사는 빼고, 뺀 번호만 따로 알려 줄 것.
- 사용자가 고른 표현: 가축 우리 → **마구간**, 애송이 → **꼬맹이**, 술법 → **마법**, 형씨 → **여러분**. 테드의 "평생 소원"은 1002000168에만(테드가 죽을 때 다시 나오는 말). 1002000158/160의 일본식 표현은 사용자 선택으로 유지.
- 대사창(∨) 개수는 바꾸지 않음 — 음성 파일 번호가 어긋남. TTS가 읽기 어려운 말더듬·긴 줄표(오、오、, 너―――무)는 피함.
- 화자(`speaker`)는 **인물만** 채움: 이름 있는 인물·이야기에 나오는 인물(노승, 말하는 검 등). 마을 아이·주민·묘비·병사·술집 주인·시스템 같은 일반 NPC는 비워 둠. 확신 없는 줄은 비우고 메모에 "화자 불확실: …". 장면 탭은 `mod/tools/projecth.js`의 `PHASES`에 범위를 적고 `projecth.js export`. 정리 끝난 씬: 1011, 1002(일부), 1003, 1103.
