# 엘도르 연대기 — 이어서 할 일 메모 (2026-11-24)

> 회사에서 하던 작업을 집에서 이어 가기 위한 메모. 상세는 각 문서에 있다.

## 오늘 정한 것 (요약)

**세계관 기준서 `eldor_world.md` 새로 만듦** — 세계·역사·세력·인물의 기준 문서.

- **세계:** 엘도르 = 대륙 이름, 레테의 세계와 **다른 세계선**(판타지 유지). 시대 기준 = **14세기 후반 프랑스** + 판타지 소재(화약 없음, 태양 신앙).
- **여울:** 세계의 흐름이 크게 꺾일 때(특이점, 레테의 말로 '꺾이는 순간') 솟는 힘. 누구도 제어 못 함. 레테는 세계선을 건너며 여울을 모으고(가두고), 마르트라도 노린다.
- **두 개의 엘도르:** 본래의 역사 = 마르트라의 폭주로 대륙 소멸 / 게임 = 레테가 여울을 가두고 떠남, 엘도르는 남음. 어떤 엔딩이든 레테는 여울을 가지고 떠난다.
- **나라:** 베르트랑의 나라 = **레오르 제국**(대륙 최강), 수도 = **제도 그리셸**. 왕국 용어는 전 문서에서 제국 용어로 바꿈(황제·황후·황명·제국 도서관 등). 북방 = 가장 사이 나쁜 나라 / 서부 = 섬 많은 봉건 교역국 / 동부 = 약소국 / 남쪽 = 보류.
- **그리셸의 비극(5년 전):** 선황 시해, 큰 민간인 피해. 전체가 **마르트라의 술책**. 시해 현장에 베르트랑과 친우가 함께 있었고 **찌른 것은 친우, 베르트랑이 목격.** 베르트랑은 시해 누명 → 중신들의 간청으로 목숨만 부지 → 재의 서약 **7년 중 5년째**.
- **인물:** 선황 **테오발 3세** / 지금 황제 **카스파르 2세**(새어머니를 따르고 사랑함, 질투·집착) / 황후 **마르트라**(정체불명, 표면적 나이, 조사 대상) / 대원수 **고티에 백작(위그)** — 속으로 믿고 겉으로 대역죄인 취급 / 친우 **이든(가칭)** — 그림자 연합 수장, 착한 사람, 마르트라를 따르는 척하다 배신 / 어린 시절 세 친구 = 베르트랑·카스파르·이든.
- **베르트랑:** 중소 귀족 가문, 실력으로 출세. 고티에와 아버지가 친구. 가문 몰락·영지 몰수·가족 전원 사망. **진짜 이름 = 베르트랑 + 가문명(미정), 지금 이름 = 애쉬.** 무기 = **붉은 도끼**(서약자에게만 대물림되는 '피를 부르는 도끼', 규칙 9 "기사의 검을 들 수 없다").
- **레테:** 황후 마르트라의 측근으로 소개 — 직함 **'황후의 낭독관'**, 별명 '황후의 마녀'(2026-11-25, '궁정 마도사'에서 변경).
- **결말 구상(작가):** 베르트랑이 고티에의 양자 → 고티에 섭정 → 새 황제.

2. **정할 것**
   - 베르트랑의 가문명 (후보: 드 코르뱅 / 드 로셰 / 드 사블)
   - '애쉬'가 서약자에게 대물림되는 이름인지
   - 이든이 선황을 죽인 이유 (**핵심, 작가 보류**)
   - 마르트라의 정체(나이를 속인 사람 / 용혈 / 다른 세계선)와 기다리는 '때'
   - 레테가 마르트라의 정체를 아는가 (추천: 모른다)
   - 카스파르의 결말 (추천: 스스로 물러나며 베르트랑을 지목)
3. **1막 이후** — 사막성채 내부와 1막 끝(원고 없음).
