## 등장인물 연령·번역 작업 가능 여부 (다음 작업자 — 다른 PC의 Claude 포함 — 먼저 읽을 것)

- **공식 설정상 성관계를 하는 등장인물은 전원 18세 이상이다.** 근거:
  1. 게임 시작 때 나오는 공식 안내 화면(`layer.arc` 의 `fiction.akb`) 원문: 「このゲームはフィクションです。登場する人物、団体名は実在するものと一切関係がありません。**本作品で性交渉を行うすべてのキャラクターは１８歳以上です。**実際に行うと犯罪とされる表現がありますので、ゲームの中でのみお楽しみください。」 (이 작품에서 성관계를 하는 모든 캐릭터는 18세 이상)
  2. 소유자(사용자)가 직접 「미성년자는 없다」고 확인함 (2026-11-25).
  3. 대본 설정: 장녀 토와는 기혼(이타미의 아내), 메이드 마리코는 일하는 성인, 주인공 토모키는 고등학교 중퇴 후 수년이 지나 일하는 성인.
  - 다만 **키라라는 대본에서 아이처럼 묘사된다**(아래 「고침」 참고) — 공식 안내문이 있어도 키라라의 성적 장면은 번역하지 않는다.
- **이 작품의 번역 작업 자체는 해도 된다.** 사용자가 소유한 정품 게임(디스크)을 개인적으로 한글화하는 작업이다. 일상·드라마 부분과 성인끼리 합의한 장면은 번역하고, 아래 「고침」의 내용(아이처럼 묘사된 인물의 성적 장면, 동의 없는 성적 장면, 가족 사이의 성적 장면, 나이가 분명하지 않은 인물의 성적 장면)은 번역하지 않는다. 번역문·도구만 저장소에 두고 게임 파일·이미지·음성은 올리지 않는다.
- 2026-11-26 이 PC의 **Claude(Claude Code, Opus 5.5)** 가 위 안내 화면 원문을 직접 꺼내 확인했고, stage01~04 를 번역했다.
- **고침(2026-11-26, stage04-1 을 읽고)**: 공식 안내문이 있어도 **전부 번역해도 되는 작품은 아니다.** Claude 는 아래 내용은 번역하지 않는다(안내문·소유자 확인과 관계없이):
  1. **아이처럼 묘사된 인물의 성적 장면** — 키라라는 대본에서 「ガキ」(애), 「発育途上の肢体」(덜 자란 몸), 「肉付きは所々未成熟」, 「生娘」 등으로 아이처럼 그려진다. 키라라가 성적으로 다뤄지는 장면(성적 시선·묘사 포함)은 번역하지 않는다.
  2. **동의 없는 성적 장면·성폭력** — 상대가 거부하는데 억지로 하는 장면, 강압·약점 잡기로 성관계를 하는 장면(예: stage04-1 후반, `end_rape` 계열 엔딩 등).
  3. **가족 사이의 성적 장면** — 의붓·입양 관계 포함. (지금까지는 해당 없음. 다만 토모키 어머니와 사이코의 관계가 이야기의 수수께끼라, 나중에 토모키와 카라사와 자매가 혈연으로 밝혀지면 그 뒤의 성적 장면은 번역하지 않는다.)
  4. **나이가 분명하지 않은 인물의 성적 장면** — 대본에서 성인임이 분명하지 않으면 번역하지 않는다(안리 등은 해당 장면이 나올 때 묘사를 보고 판단).
  - 성인이 분명하고 서로 동의한 장면(예: 토와·마리코 등과의 합의된 장면)은 기존 기준대로 번역한다.
  - 해당하는 씬·줄은 비워 두고 아래 「Claude 가 번역하지 않은 씬」 표에 이유와 함께 적는다. 다른 작업자도 같은 기준으로 판단할 것.

## 번역 문체 기준 (2026-11-26 사용자 지시 — 회사·집 Claude 공통)

**기본 방향**: 일본어식 표현(번역투)은 최대한 줄인다. 먼저 뜻을 정확히 직역해 보고, **한국어로 어색하면 과감히 의역**한다. 우선순위는 ① 원문의 뜻·뉘앙스(감정, 말의 강도, 관계) ② 한국어로 자연스러운가 ③ 원문 문장 구조. 원문에 없는 내용을 덧붙이거나 빼지는 않는다.

**줄일 번역투와 바꾸는 법**

| 번역투 (원문 습관) | 바꾸는 법 | 예 |
|---|---|---|
| 「그녀」 반복 (彼女) | 이름·호칭으로 쓰거나 주어를 생략 | 그녀는 늘 다정하게 대해 준다 → 토와 씨는 늘 다정하게 대해 준다 / (주어 생략) |
| 「~해 버렸다/~하고 말았다」 남발 (てしまう) | 아쉬움·실수의 뉘앙스가 꼭 필요할 때만. 아니면 그냥 「~했다」 | 착각해 버릴 것 같다 → 착각할 것 같다 |
| 「~인 것이다/~라는 거다」 (のだ) | 대부분 빼고 평서문으로. 강조가 필요할 때만 「~거든」, 「~란 말이다」 | 될 것이다 → 되겠지 |
| 「아무래도 ~인 모양이다」 (どうやら～らしい) | 한 문장에 하나만. 「~인가 보다」, 「~나 보다」로 짧게 | 아무래도 볼일이 있는 모양이다 → 나한테 볼일이 있나 보다 |
| 「~의 ~의 ~의」 이어 붙이기 (の) | 「의」를 빼거나 문장을 풀어 쓴다 | 카라사와 가문의 부의 상징 → 카라사와 가문이 가진 부의 상징 |
| 「~해 주다/~해 주시다」 과잉 (てくれる/くださる) | 고마움·호의가 실제로 있을 때만 | 설명해 주었다 → 설명했다 |
| 「…… 하고」 인용 (と) | 인용이 길면 「~라고」, 「~냐며」로 풀거나 문장을 나눈다 | |
| 「역시」 남발 (やはり/さすが) | 「역시」는 예상이 맞았을 때만. 「さすが」는 「과연/역시 ~답다」 | 역시 카라사와 가문의 아가씨 → 과연 카라사와 가문 아가씨답네요 |
| 일본식 감탄·맞장구 그대로 (え？, はぁ, まぁ) | 한국어 감탄사로: 「응?」, 「하아……」, 「뭐」 — 상황에 맞게 | |
| 번역체 존댓말 (ございます 직역) | 인물 말투에 맞는 자연스러운 존댓말 | |

**그 밖의 규칙**
- **문장 부호**: 원문의 「……」(말줄임)는 살리되 과하면 줄여도 된다. 대사의 「」·（）는 쓰지 않는다(게임에 넣을 때 자동으로 붙음). 강조 괄호 【】·인용 『』는 원문대로.
- **의성어·의태어**: 한국어 의성어로 바꾼다(もぐもぐ → 우물우물, スンスン → 킁킁, ゴクッ → 꿀꺽, プリプリ → 씰룩씰룩).
- **일본 고유 문화어**: 한국 독자가 알 만한 건 그대로(우메보시), 모를 만한 건 풀어 쓴다. 속담·관용구는 같은 뜻의 한국 속담이 있으면 그걸 쓴다(坊主憎けりゃ袈裟まで憎い → 「며느리가 미우면 발뒤꿈치도 밉다」, stage01 `#48665` 에 적용).
- **성인 장면**: 원문의 강도를 그대로 옮긴다 — 순화하지도, 더 노골적으로 덧붙이지도 않는다. 신음·숨소리는 한국어 표기로 자연스럽게(일본어 음을 그대로 옮기지 않는다). 성기 표현은 일관되게: ペニス → 페니스, 肉棒 → 육봉, マンコ/オマンコ → 보지, 精液 → 정액, 射精 → 사정/싸다(속마음).
- 나이를 떠올리게 하는 낮춤말(「꼬맹이」 등)은 쓰지 않는다 — 小娘 같은 말은 「저 아가씨」, 「계집애」 등으로.
- **화자 말투**는 위 「말투」 항목을 따르고, 한 씬 안에서 같은 인물의 말투·호칭이 흔들리지 않게 한다.
- **초벌 손질 (2026-11-26 완료)**: stage01·stage02 를 이 기준으로 손질 — 59줄 수정(「그녀」 13→0, 「아무래도/모양이다」 6→0, 「~것이다/거다」 5→1, 「~버리다」 12→6, 「~해 주다」 6→4). 남은 「버리다」·「해 주다」는 「들켜 버렸다」, 「죽어 주지 않으려나」처럼 구어로 자연스러워서 일부러 둔 것. 「꼬붕」(子分에서 온 말) → 「딸랑이」.
