음성 분할·자막 도구

통으로 녹음한 음성 파일(문단 사이 1.5초 무음)을 올리면 무음 한가운데서 문단별로 나누어 저장하고, 대본으로 자막(SRT)을 만들 수 있는 업무용 도구입니다. 원본 파일은 바꾸지 않습니다. 크롬·엣지용.

여기에 오디오 파일을 끌어다 놓거나 클릭해서 고르세요 (WAV 권장)

클릭 = 경계 추가 · 빨간 선을 끌면 옮기기 · Shift+클릭 = 가장 가까운 경계 지우기 · 휠 = 확대/축소(마우스 위치 기준), 확대하면 아래 막대로 좌우 이동 · 재생 중 Space(또는 M) = 지금 위치에 경계 찍기 · 표의 「끝」 칸에서 경계 시간을 숫자로 고칠 수 있음 · 두 번 녹음됐거나 뒤쪽이 무음인 부분은 경계로 따로 떼어 「저장」 체크를 풀면 저장·이름 순서에서 빠짐(붉은 띠) · 무음을 더 붙이려면 빨간 선 양쪽의 ＋ 버튼(왼쪽 = 앞 조각의 뒤, 오른쪽 = 뒤 조각의 앞, 파일 맨 앞·맨 끝에도 있음)과 그 옆의 － 버튼(한 번에 기본값만큼 줄이고 0에서 멈춤, 0이면 흐리게 꺼짐)이나 표의 「무음 추가 앞 / 뒤」를 쓰세요. 추가한 무음은 「듣기」·「전체 재생」에도 그대로 들어가고 저장됩니다.
빨간 선 = 경계, 회색 띠 = 찾은 쉼, 빗금 회색 띠 = 추가한 무음(+초), 초록 선 = 재생 위치. 재생 중인 버튼을 다시 누르면 정지합니다.

저장#이름시작끝 (경계, 초)길이무음 추가 앞 / 뒤
출력: 44.1kHz 모노 고정

OGG는 처음 저장할 때 인코더(약 0.8MB)를 인터넷에서 한 번 받아 옵니다. 품질 5 ≈ 160kbps, 3 ≈ 112kbps. 표준 규격(44.1kHz 모노)으로 저장합니다.

「음량 맞추기」를 체크하면 「저장」이 체크된 조각 전체의 음량을 목표 값에 맞춰(모든 조각에 같은 배율을 곱함) 「듣기」·「전체 재생」, 파형 크기, 저장(폴더·ZIP)에 똑같이 적용합니다. 체크하지 않으면 원래 음량 그대로 들리고 저장됩니다. 작게 녹음된 소리는 크게 키워져 재생되니, 체크하기 전에 PC 음량을 확인하세요. 형식(WAV/OGG)과 앞뒤 무음, 파일 이름은 위 설정을 그대로 따릅니다. 음량은 모노 파일을 양쪽에 같은 소리로 재생하는 기준으로 계산해서, 같은 방식으로 잰 샘플 음성(스테레오)과 바로 비교할 수 있습니다. 피크 상한에 걸리면 목표보다 조금 낮게 맞춥니다.

저장 위치: 프로젝트의 voice 폴더(다른 위치로 연결된 폴더라 중복 저장되지 않습니다).

자막(SRT) 만들기

위 「대본」을 「저장」이 체크된 조각의 말하는 구간(앞뒤 무음 제외)에 맞춰 자막으로 만듭니다. 자막 시간은 「통으로 저장」·「전체 재생」과 같은 시간축(추가한 무음·앞뒤 무음·체크를 푼 조각 반영)이라, 통으로 저장한 파일을 캡컷에 올릴 때 그대로 맞습니다. 문단 수와 조각 수가 같으면 문단별로, 다르면(문단 안에 무음을 넣으려고 경계를 더 찍은 경우 등) 전체 소리에 글자 수 비율로 나누고 쉼 동안에는 자막이 남지 않게 합니다. 문장 끝에서 자르고, 한 줄 최대 글자 수를 넘으면 어절 사이에서 고르게 나눕니다. 시간은 글자 수 비율로 나눈 값이니 아래 칸에서 고친 뒤 저장하세요. 캡컷: 캡션 → 캡션 추가 → 파일 가져오기.
