1. **번역** — 씬 단위로 `scene.js set`을 써서 `korean`을 채운다(변경 기록이 남음).
2. **검수** — 작업실·원고 읽기에서 🚩 표시 → `review.js`로 처리.
3. **게임에 적용** — 번역한 `.ks`를 패치(`patch.xp3` 또는 폴더 덮어쓰기)로 넣고, 한글 폰트·로캘 문제를 확인한다.
