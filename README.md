# Project_H 통합관리

대사, 녹음용 대본, 음성 및 검수 상태를 씬 단위로 확인하고 수정하기 위한 정적 관리 페이지입니다.

최신 검수본의 10,917개 행과 60개 씬이 포함되어 있습니다. 브라우저에서 수정한 내용은 해당 브라우저의 로컬 저장소에 보관됩니다.

## 포함된 화면

- 씬별 목록과 단계별 탭
- 영어 원문, 한국어 대사, 녹음용 대본 및 원본의 모든 관리 열
- 씬, 화자, 음성 상태, 대본 유무 및 검색 필터
- 선택 행 상세 확인과 브라우저 로컬 수정

## 실행

정적 웹 서버에서 이 폴더의 `index.html`을 열면 됩니다.
