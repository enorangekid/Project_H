## 9~10장 초안에서 새로 정한 것 (검토 필요)

- **일행 나누기 (E1-14)** — 원고의 "로크는 오른쪽 골목, 엘린은 이쪽"을 선택으로. 골목에 간 동료가 전투를 돕고, 신전에 간 동료가 다른 단서를 가져온다(엘린: 서고로 곧장 갔다는 증언 / 로크: 짐 실은 말이 남쪽으로). 레테는 조력자라 항상 베르트랑과 함께.
- **약탈자의 정체 (E1-16 추리)** — 곡식은 버리고 서고로 곧장, 제도의 새 은화, 같은 편자, 굳은살 없는 손 → "약탈자 옷을 입은 심부름꾼". 찢어 낸 지도 귀퉁이는 도서관에서 도둑맞은 지도와 같은 필체. 도서관 도난 → 마을 습격이 하나로 이어진다.
- **오렐 첫 등장** — 원고의 여성 성직자 대사를 살리며 남성으로. 첫 장면부터 술병을 먼저 챙긴다("지팡이는 빛이 지켜 주시지요. 이건 제가 지켜야 하고요"). 밤에 "오늘은 넷을 살렸습니다".
- **"태양의 길"은 글로 다 적혀 있지 않다** — 오렐이 외워 둔 길. 기록을 빼앗긴 그림자 연합 쪽보다 오렐이 있는 일행이 유리한 이유. 성채 진입 퍼즐로 이어질 여지.
- **모래폭풍 선택 (E1-19)** — 피하면 안전하지만 늦고, 강행하면 다치지만 앞서 간 자들과 거의 동시에 도착(`arrive_early`). 성채 내부 시나리오의 시작 조건으로 쓸 수 있다.
- **레테의 미래어** — "섭씨로… 아니, 잊어 주세요." 평소 장면의 가벼운 어긋남.
- 새 변수: `split` · `clue_raider_horses` · `clue_raider_hired` · `clue_went_straight` · `clue_raider_south` · `deduce_raiders` · `arrive_early`

## 초안에서 새로 정한 것 (검토 필요)

- **원고의 황궁 훈련장 재회 → 망루 방문.** 엘린이 성 밖 죄인의 거처까지 걸어온다.
- **엘린의 "빚"과 "늦게 왔다"** — 과거를 정하지 않고 여지만 남기는 대사. 배신 구상에 맞춰 바꾸면 된다.
- **서랍 뒤판** — 로크의 히든 스킬이 있으면 얻는 추가 단서(`clue_back_panel`). 없어도 추리는 끝까지 풀린다.
- **장화 밑창의 밀랍** — 레테의 결백을 증명하는 단서. 레테다운 관찰.
- **"죄인이 죄인을 감시한다"** — 경비대장이 레테를 베르트랑에게 맡기는 조건.
- **레테의 그림자 연합 문양 반응** — "아주 오래전에." 시리즈 떡밥, 확정하지 않음.
- **이름 없는 꾸러미의 궁정식 매듭** — 황후의 흔적. 레테만 알아채고 말하지 않는다.
- **로크와 성냥** — "덫에 쓰면 좋겠군요." 흔적을 읽는 두 사람의 첫 교감.
