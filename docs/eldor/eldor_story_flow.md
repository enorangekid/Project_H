# 엘도르 연대기 — 임무 출발 이후 이야기 흐름 정리

**버전:** v0.1 / 2026-11-25
**범위:** 1막에서 황명을 받고 사막으로 출발한 뒤(E1-12 이후)부터 결말까지의 큰 흐름.
**재료:** 1막 스크립트(E1-13~E1-20), 세계관 기준서(`eldor_world.md`), 옛 텍스트 RPG 초안 정리(`eldor_textgame_notes.md`), 기획서.

**표기:** [스크립트 있음] 이미 씀 · [확정] 작가 결정 · [제안] 내 정리안 · [작가] 작가가 정할 것(먼저 채우지 않음)

---

## 한눈에

```
1막 (계속)  모래바람의 마을 → 사막 → 사막성채 → 빛의 제단 → 제도 귀환        ← 아르테미스
2막         북쪽 설원 — 그림자 연합 요새, 미카                                  ← 복수가 흔들린다
3막         제도 그리셸 — 마르트라, 검은 해, 여울                               ← 진실과 대가
결말        레테가 여울을 가두고 떠난다 / 베르트랑의 처지는 엔딩마다
```

**막마다 하나씩만 연다 [확정 원칙]:** 1막 = 연합 뒤에 제도의 돈이 흐른다(의심은 황제 쪽으로) / 2막 = 이든의 배신에 다른 이유가 있었다 / 3막 = 마르트라가 흑막이다.

**한 막의 틀 [제안, 초안에서]:** 거점 → 황명 → 자료 조사 → 원정(조사·간부와의 대결) → 무기·단서 확보 → **귀환·보고(공은 기록되지 않는다)** → 휴식·정보 → 다음 황명.

## 1막 후반 — 아르테미스 [9~10장 스크립트 있음, 11~12장 제안]

### 9장 모래바람의 마을 [스크립트 있음 — E1-13~E1-17]
사막 경계 → 약탈당한 마을 조사 → **일행 나누기 선택**(로크/엘린을 골목·신전으로) → 골목에서 오렐 구출(인질 선택) → **추리: 약탈자는 누구인가** = "약탈자 옷을 입은 심부름꾼"(제도의 새 은화·같은 편자·굳은살 없는 손·도서관 지도와 같은 필체) → 마을의 밤.

### 10장 사막성채로 향하는 길 [스크립트 있음 — E1-18~E1-20]
오렐 합류('태양의 길'은 그의 기억 속에) → 사막, 앞서 간 무장 일행의 흔적 → **모래폭풍 선택**(`arrive_early`) → 사막성채 앞 야영, 밤의 금속 소리.

### 11장 사막성채 — 디테일 [E1-21·E1-22 확정, 2026-11-25]

**E1-21 접근**
- 밤의 금속 소리 = 연합이 성채 문을 억지로 열던 소리. 아침, 연합이 먼저 안에 있다.
- **루트 선택:** 남쪽 정문(언제나 / 정면이라 들킴, 기습 없이 보스전) · 동쪽 절벽(**로크 '탐색'** 필요 / 들키지 않고 진입, 조사 하나 더) · 북쪽 외곽(언제나 / 늦음, 연합이 안쪽을 먼저 뒤집음).
- `arrive_early`면 연합이 아직 문을 다 못 열어 어느 루트든 수월.
- **반전:** 오쿨루스는 숨은 것을 보는 자 — 절벽으로 숨어들어도 결국 들킨다. "아아, 거기 계셨군요. 재를 진 분." 다만 늦게 들킨 만큼 조사 시간을 번다.

**E1-22 성채 안 — 조사 (보스전 약점을 여기서 찾는다)**

| 조사할 것 | 찾는 사람 | 단서 |
|---|---|---|
| 태양의 방 — 천장 구멍과 기울어진 거울들 | **오렐**('태양의 길' 표시) | 정오에 빛을 안쪽으로 끌어들이는 장치 → 약점 **빛** |
| 연합이 버린 천막 — 사도의 낡은 성의, 기도문 | 레테 | 그가 전대 오쿨루스(사도)를 이은 자. 기도문 "스승의 눈을 찌른 자" |
| 늘 한쪽 벽에 붙어 걷는 발자국 | 베르트랑 또는 레테 | 한쪽을 못 본다 → 약점 **사각** |
| 'B' 명단의 찢긴 쪽지 | 엘린 | 심문용(B-12·B-14 '이송', B-13 '북쪽') |

- 핵심은 **태양의 방**과 **발자국**. 둘 다 못 찾으면 정면 승부 → 부상.
- 오쿨루스는 햇빛을 싫어해 그늘진 안쪽에만 머문다 → **정오에 태양의 방으로 끌어내는 것**이 보스전의 그림.

### 11~12장 스크립트 [스크립트 있음, 2026-11-25 — 사용자 부재 중 진행, 검토 대기]

`eldor_act1_script.md` E1-21~E1-28. 1막 끝 = 보스 오쿨루스 → 생포·심문("B-13, 북쪽", 빛의 제단, 날개 문장의 사자) → 알현("또 살아 돌아왔고", "기록되지 않는다") → 감옥에서 독살(자결로 덮임, 궁정식 매듭·사자 인장 교대) → 망루의 밤 → **이든 장면("…그렇군. 아쉽게 되었어.")** → VO 베르트랑. **빛의 제단·아르테미스는 2막 이후.** 아래 '처음 정리' 표는 이 확정 흐름 이전의 안(12장 빛의 제단 포함)이라 참고용.

## 2막 — 북쪽 설원: 복수가 흔들린다 [제안 뼈대]

- **무대:** 북쪽 — 제국과 가장 사이 나쁜 나라와의 국경, 브룩타운과 첫 봉인문의 땅. 설원의 **그림자 연합 요새**. 프롤로그의 땅으로 돌아가는 구조.
- **임무:** 황명은 '북방 국경의 연합 요새 정찰'. 로크에게는 미카.
- **미카 [확정+작가]:** 연합에 잡혀 있다(확정). **흑룡 부활에 중요한 역할**(확정 방향) — 마법진과 특별한 금속에 묶여 있고, 구출 중 의식이 발동할 수 있다. **쉽게 구출되지 않는다**(작가). 초안의 방향 "봉인을 막는 열쇠이자 연합이 필요로 하는 존재"(양날). 정확한 역할 [작가].
- **네임드 간부 둘째 [제안]:** 함정과 매복의 전술가, 유리할 때만 싸우고 **도망쳐 다시 나타나는 숙적형**. 협곡 매복을 역이용하는 선택(작가가 초안에서 고른 전술).
- **이든 [작가]:** 2막에서 처음 그림자를 드러낸다 — 직접 대면할지, 흔적만일지. 드러나는 것은 "죽이지 않았다"가 아니라 **"죽였지만 다른 이유가 있었다"**의 첫 조각. 동기는 작가 보류.
- **고티에의 재판 기록 [제안]:** 제국 도서관에서 찾는 음성 문서 — 처음엔 고티에가 베르트랑을 미워하는 것으로 읽힌다.
- **마르트라 조사 [제안]:** 가짜 바닥 1~2겹(동정이 가는 답). 레테의 수첩에 어긋남이 쌓인다.
- **동료:** 로크는 1막에서만 고정 — 2막에서 미카 구출 뒤 어떻게 되는가 [작가]. 사막 출신 동료(초안의 사르딘 자리)를 둔다면 남쪽에서 합류해 로크의 '탐색' 자리를 잇는 구도 [선택].
- **2막 끝의 상실 [작가]:** 원래 구상의 '상실'(동생의 죽음)은 베르트랑의 가족이 이미 그리셸에서 모두 죽은 것으로 옮겨 갔다. 2막 끝에 무엇을 잃는가는 다시 정할 것.

## 3막 — 제도 그리셸: 진실과 대가 [제안 뼈대]

- **마르트라가 흑막이다** — 마지막 바닥. 앞선 바닥들이 모두 그녀가 만든 이야기였다.
- **그리셸의 비극의 진실**, 이든이 마르트라를 **따르는 척하다 배신**한다(확정).
- **검은 해 [제안]** — 봉인이 가장 약해지는 날, 바르카스와 엘도르가 꺾이는 순간 → **여울.**
- **아르테미스가 빛을 되찾는다** — 태양의 제단·오렐·'태양의 길'.
- **클라이맥스 [확정]:** 마르트라가 여울을 얻기 직전, 레테가 그 정체를 말한다("지금껏 누구도 제어하지 못했어요. 당신도 마찬가지일 거예요.")와 함께 여울을 가둔다. **클라이맥스 분담 [제안]:** 여울은 레테, 마르트라·이든·카스파르와의 매듭은 베르트랑.
- **카스파르의 결말 [작가]** — 추천: 스스로 물러나며 베르트랑을 지목.

## 결말 [확정 골격]

- 어떤 엔딩이든 **레테는 여울을 가지고 세계선을 떠난다.** 달라지는 것은 **베르트랑의 처지.**
- **작가 구상:** 베르트랑이 고티에의 양자 → 고티에 섭정 → 새 황제. 진짜 이름(베르트랑 + 가문명)을 되찾는 것과 맞물린다.

## 정할 것 (흐름 기준, 급한 순서)

1. **1막 사막성채 간부** — 이름, 성격 한 줄(광신도 지휘관 방향 괜찮은지).
2. **아르테미스를 1막에서 손에 넣는가** — 제안: 빛을 잃은 채 얻고, 황제에게 빼앗긴다. / 대안: 1막은 위치 단서까지만.
3. **태양의 검** — 버린다(추천) / '빛을 되찾는 과정'으로 녹인다 / 따로 둔다.
4. **'B' 명단의 뜻과 미카의 역할.**
5. 2막 끝의 상실, 로크의 2막 이후.
6. 이든의 동기(핵심, 보류 중).
