# 프롤로그

### P-00 프롤로그
> 배경: 검은 화면 → 북쪽 산맥 원경 · 등장: 나레이션 · 진입: 게임 시작

N: 레오르 제국은 수백 년 동안 평화를 누려왔다. 북쪽 산맥은 눈과 바람으로 둘러싸인 변경이었고, 그 너머에는 오래된 전설과 잊힌 유적만이 남아 있다고 여겨졌다.
N: 그러나 어느 날부터 북쪽의 마을들이 하나둘 불타기 시작했다.
N: 밤하늘을 가로지르는 거대한 그림자를 보았다는 증언이 이어졌고, 가축과 사람이 흔적도 없이 사라졌다.
N: 사람들은 오래된 이름을 입에 올리기 시작했다.
N: 바르카스.
(연출: 이름이 화면 가운데 한 번 떠오르고 사라진다)
N: 검은 용. 아주 오래전 인간들의 손에 봉인되었다고 전해지는 재앙이었다.
N: 제국은 모험가와 병사들을 불러 모았다. 그러나 부름에 응한 이는 많지 않았다.
N: 그래서 제국은 한 사람을 북쪽으로 보냈다.
N: 문장 없는 방패를 든 사내. 베르트랑이었다.

N: 기사라면 검을 차고 다녔을 자리였다.
(연출: 방패 클로즈업)
