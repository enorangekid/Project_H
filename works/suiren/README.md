## 할 일 (순서대로)

1. **번역** — 씬 단위로 `scene.js set`을 써서 `korean`을 채운다(변경 기록이 남음).
2. **검수** — 작업실·원고 읽기에서 🚩 표시 → `review.js`로 처리.
3. **게임에 적용** — 번역한 `.ks`를 패치(`patch.xp3` 또는 폴더 덮어쓰기)로 넣고, 한글 폰트·로캘 문제를 확인한다.

## 회사·집 공용 번역 메모

- **시작 전**: 공유 Project_H 폴더의 `main`에서 GitHub 최신본과 로컬 상태를 확인한다. 작업 브랜치를 바꾸지 않는다. `node tools/scene.js --work suiren list`에서 번역 진행률을 확인하고, 이어 쓸 씬과 직전 완료 씬을 함께 읽는다. 이 메모를 작성한 시점에는 공통 `com_01`~`com_13_02h` 14개 씬이 완료됐고, 다음은 `com_13_03`이다. 실제 진행률은 작업실 데이터를 기준으로 한다.
- **기준 문체**: 일본어 원문을 직접 읽고 자연스러운 한국어 어순으로 옮긴다. 인사, 망설임, 반응, 말의 강도와 관계 변화는 살린다. 카즈키의 나레이션은 담백한 1인칭으로 쓰고, 속말은 “벌써 몇 년 만이지?”처럼 짧고 자연스럽게 푼다. 같은 장면의 시제와 대사 표기(`「…」`, `……`)는 인접 완료 행을 따른다.
- **캐릭터 말투**: 스이렌은 “둘 다 얼른 들어와. 거실에 점심 차려 뒀어.”(`com_11`)처럼 다정하고 편한 반말을 쓴다. 시온은 초반에 “……원래 남자였잖아.”(`com_04`)처럼 짧게 툭 던지지만, 경계가 풀린 장면에서는 자연스럽게 길게 말한다.
- **호칭은 관계에 맞춰 구분**: 카즈키의 어릴 적 애칭 `すい姉さん`은 **스이 누나**, `水蓮姉さん`은 **스이렌 누나**. `com_03#204~215`에서 호칭을 바꾸는 흐름을 살린다. 이후에도 원문이 애칭으로 돌아가면 그대로 살린다(`com_09#204`). 시온이 스이렌을 부르는 말은 **언니**, 스이렌이 카즈키 앞에서 자신을 부르는 말은 문맥에 따라 **누나**.
- **고정 표기**: `水蓮` → **스이렌**, `紫苑` → **시온**, `和樹` → **카즈키**, `若弥` → **와카미**, `水無瀬島` → **미나세섬**, `コテージ` → **숙소**. 처음 정한 이름·장소·호칭은 다음 작업자가 볼 수 있게 여기에 추가한다.
- **작업 범위**: 본편 번역은 `korean`에 쓰고 원문·행 ID는 보존한다. 검수 이슈는 해당 행에 메모한다. 더빙 필드는 비워 둔다. 커밋·푸시 요청은 다른 작품 변경을 제외하고 Project_H의 `main`에서 처리한다.
- **검수 후보**: `com_10#281`은 아침 인사가 “응”으로 바뀌어 원문 인사 복원 검토, `com_12#238`은 “따라” 반복 윤문 검토.
