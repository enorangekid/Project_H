# 엘도르 연대기 — 옛 텍스트 RPG 초안 정리 (2026-11-25)

> 예전에 GPT와 텍스트 RPG처럼 놀면서 만든 초안(키드 일행의 훈련장 → 사막 마을 → 사막성채 → 태양의 검 → 귀환 → 북쪽 설원 미카 구출)을 정리한 메모.
> **GPT가 지어낸 인물·수치·이름은 설정이 아니다.** 여기서 중요한 것은 ① **작가가 직접 고르거나 요청한 것** ② GPT 재료 중 지금 설정에 쓸 만한 것.
> 확정 설정(`eldor_world.md`, `eldor_master_plan.md`)이 항상 우선. 이 문서는 사막성채 내부·1막 끝·2막을 짤 때 꺼내 쓰는 재료함.

---

## 1. 작가의 취향 — 선택에서 드러난 것

| 신호 | 근거(작가의 선택) |
|---|---|
| **먼저 알아보고 움직인다** | 출발 전 '사막 생존 정보 조사', 빠른 협곡 대신 안전한 평원, 제단 앞에서 '매복 확인 후 접근', 성채에서 며칠 휴식·정보·정비 |
| **싸움은 수단, 목표는 정보** | 네임드 적의 마지막 일격 앞에서 주어진 선택지를 모두 거부하고 **"잠깐 죽이지 말고 정보를 얻어야지"** — 조사형 어드벤처라는 방향의 뿌리 |
| **목표 우선, 불필요한 싸움 회피** | 연합 흔적은 확인만 하고 단서부터 / 적을 발견하자 기습 대신 은밀 우회 |
| **상대의 수를 읽고 역이용** | 마법사부터 집중 공격, 협곡 매복을 역이용한 함정 |
| **주인공 + 전문가 동료의 합** | "키드·사르딘 조합", 동료가 묶고 주인공이 결정타 — 동료 선택 시스템과 맞음 |
| **판이 깔리면 망설이지 않음** | 전투 후 바로 진입, 중심부로 바로 돌진 |
| **임무 뒤엔 반드시 돌아와 보고** | 무기 확보 후 즉시 귀환·보고 — 재의 서약과 맞음 |
| **중요한 일은 쉽게 풀리면 안 된다** | 미카를 쉽게 구출하자 **"너무 쉽잖아, 흑룡 부활에 중요한 역할이라며"** |

## 2. 작가가 직접 요청·정한 것

- **큰 구간마다 그림자 연합의 이름 있는 간부**를 하나씩 둔다(초안: 다르카스·말릭·실바누스/오르칸 — 이름은 GPT 것).
- **사막성채 = 아르테미스를 얻는 곳, 동료가 모이는 곳.** "사막성채에서 얻을 수 있는 거 아니었어?" / "사막성채에서 마지막 파티원을 만나게."
- **아르테미스가 중심 목표.** GPT가 '태양의 검'을 꺼내자 "아르테미스는 어떻게 된 거야~"로 되돌림. (다만 이후 태양의 검 루트도 진행함 → 아래 '정할 것')
- **미카(로크의 동생)는 그림자 연합에 잡혀 있다.**
- **미카는 흑룡 부활에 중요한 역할을 할 수 있다** — 그래서 구출은 쉽지 않아야 한다.

## 3. 지금 설정으로 쓸 재료

### 사막성채 (1막 끝 — 지금 비어 있는 곳)
- **접근 루트 셋:** 남쪽 정문(견고) / 동쪽 절벽(은밀, 정찰 동료 필요 — 로크 '탐색') / 북쪽 외곽(멀지만 적 주력 회피). `arrive_early`와 묶어 연합과 마주치는 시점이 달라지게.
- 성채는 **그림자 연합이 먼저 점거**(1막 E1-19 "앞서 간 무장 일행"과 이어짐).
- 성채 안의 갈림길, 중심부로 가는 큰 문, 연합 마법사의 함정.
- **네임드 간부를 사로잡아 심문**하는 장면 = 1막 클라이맥스 후보. 레테가 진술의 거짓을 읽는다. (모래바람 마을 약탈자 심문과 같은 결)
- 간부는 **흑룡 부활을 믿는 광신도** — 마르트라를 모른 채 그녀의 손발로 움직인다(연합 중 마르트라의 돈을 받는 쪽). 심문해도 진실의 일부만.
- **벽의 룬 → 고대 지도 → 아르테미스가 봉인되었던 '빛의 제단' 위치.** 창 자체는 성채에 없다 → 1막을 닫고 2막을 여는 고리. 룬을 읽는 사람은 오렐(히든 '고대 문자 해독' 후보) 또는 레테.
- 아르테미스는 **옛날 흑룡을 봉인할 때 쓰인 창**, 지금은 **빛을 잃고 잠들어** 있다 — "사원(태양의 제단)에서만 빛을 되찾는다"는 대사를 창에 붙인다. 오렐의 태양 지팡이·'태양의 길'과 이어짐.
- 점령한 성채를 며칠 머무는 **임시 거점**으로(막마다 거점이 바뀌는 구조 — 1막 까마귀 망루처럼).

### 이야기 구조
- **한 막의 틀:** 거점 → 임무 → 원정(조사·간부와의 대결) → 무기·단서 확보 → **귀환·보고** → 휴식·정보 → 다음 임무.
- **귀환 보고는 뒤집는다:** 초안의 환영·칭찬 대신, 무기를 들고 와도 환영하는 사람이 없고, 카스파르는 "그 공은 기록되지 않는다", 무기는 황제가 거둬 간다.
- **그림자 연합과의 선점 경쟁** — 늘 한발 앞서거나 뒤에 있는 적과 단서를 다툼.
- **연합끼리 싸운 흔적**(모래언덕 밑 화살·마법 흔적) — 이든 쪽과 마르트라 쪽의 갈라짐을 흐리게 비치는 복선 후보(다른 해석이 가능한 모양으로).
- **출발 전 준비 선택**(정보 수집 / 정비 / 강행)을 구간마다 가볍게 반복 — 1막 E1-19 모래폭풍 선택이 이미 이 모양. '기사단 지원 요청'은 재의 서약자라 **거절당하는 선택지**로.
- 전투는 **나레이션 + 결정적 순간의 선택지 하나 + 결과 변수**(프롤로그 방식). 전략 선택(돌진 / 위험한 적 먼저 / 방어 후 반격)은 선택지로 살린다.

### 미카와 2막
- **2막 무대 후보: 북쪽 설원의 그림자 연합 요새** — 미카가 갇혀 있다. 북쪽 = 제국과 가장 사이 나쁜 나라, 브룩타운·첫 봉인문의 땅 → 프롤로그의 땅으로 돌아가는 구조. 로크가 다시 중심에.
- 미카는 **마법진·특별한 금속에 묶여** 있고, 구출 중에 의식이 발동할 수 있다 — 구출 자체가 위험한 작전.
- 초안의 미카 대사 방향: **"흑룡 부활을 막는 열쇠이면서, 연합이 필요로 하는 존재"** — 양날의 열쇠.
- **B-13과의 연결 [제안]:** 'B' 번호 = 연합(그 뒤의 마르트라)이 모으는 사람들의 번호 — 예: 봉인과 이어진 혈통. 봉인은 희생으로 유지되니, **봉인을 지킬 수 있는 피가 봉인을 열 수도 있다.** 1막 명부에서 B-13의 줄만 지워져 있다 = 미카가 특별하다. B-12·B-14는 남쪽 사막에.
- 사막 출신 동료의 자리(초안의 사르딘) — 지역 동료 영입의 첫 사례 후보, 제국이 '미개하다'고 부르는 남쪽 사람의 눈. 로크와 역할이 겹치므로 로크가 빠지는 시기에 그 자리를 잇는 구도로.

## 4. 버릴 것

턴제 전투·체력 표·수치 강화(+15% 등)·경험치 사냥 / 마법사 엘린(확정: 가느다란 검·언변·'방패') / 여성 성직자 라니엘(확정: 오렐) / 검을 든 키드(확정: 붉은 도끼) / 환영받는 귀환 / GPT가 지은 이름 — 사르딘(정어리), 다르카스(바르카스와 한 글자 차이), 말릭(실존 이름), 실바누스·오르칸. **인물이 맡던 자리는 살리고 이름은 새로 짓는다.**

## 5. 정할 것

1. **태양의 검** — 아르테미스 하나로 갈지(추천: 태양의 검은 버리거나 '아르테미스가 빛을 되찾는 과정'으로 녹임), 둘 다 둘지.
2. **미카의 역할** — 흑룡 부활의 열쇠인가, 봉인의 열쇠인가, 둘 다인가. B 번호의 뜻.
3. **연합 간부진** — 몇 명, 이름, 누가 이든 쪽이고 누가 마르트라 쪽인가. 1막 사막성채의 간부부터.
4. **사막 출신 동료**를 둘지.
5. 사막성채 → 빛의 제단 → (태양의 제단) → 북쪽 설원의 순서를 막에 어떻게 나눌지.
