- 말투(2장~): 시에는 콧대 높은 반말, 주인공을 「하시즈메」. 안리는 감정 없는 존댓말, 「하시즈메 씨」. 키라라는 애교 반말, 주인공을 「오빠」, 자기를 「키라라」, 「키라라짱이라고 불러」. 紫衣ねーさま/お姉様 = 「시에 언니」. 토모키는 아가씨들에게 존댓말(「시에 아가씨」·「안리 아가씨」·「키라라 아가씨」/「키라라짱」). 지명 黄金浜 = 코가네하마, 唐沢島 = 카라사와섬. 스크립트를 읽으면서 이 표를 늘린다.

- 말투: 토모키 서술·속마음은 반말 1인칭(나), 토와에게는 존댓말, 이타미에게는 깍듯한 존댓말. 토와는 부드러운 존댓말. 이타미는 거친 반말. 호칭 橋詰さん = 하시즈메 씨, 永遠奥様 = 토와 사모님, 彩子奥様 = 사이코 사모님, 永遠さん(속마음) = 토와 씨.
- 쓰지 말 것: 한자(빌린 한자 자리와 겹칠 수 있음), KS X 1001 밖의 드문 한글. `·` 같은 기호는 도구가 Shift-JIS 기호로 바꿈.

## 번역 문체 기준 (2026-11-26 사용자 지시 — 회사·집 Claude 공통)

**기본 방향**: 일본어식 표현(번역투)은 최대한 줄인다. 먼저 뜻을 정확히 직역해 보고, **한국어로 어색하면 과감히 의역**한다. 우선순위는 ① 원문의 뜻·뉘앙스(감정, 말의 강도, 관계) ② 한국어로 자연스러운가 ③ 원문 문장 구조. 원문에 없는 내용을 덧붙이거나 빼지는 않는다.

**줄일 번역투와 바꾸는 법**

| 번역투 (원문 습관) | 바꾸는 법 | 예 |
|---|---|---|
| 「그녀」 반복 (彼女) | 이름·호칭으로 쓰거나 주어를 생략 | 그녀는 늘 다정하게 대해 준다 → 토와 씨는 늘 다정하게 대해 준다 / (주어 생략) |
| 「~해 버렸다/~하고 말았다」 남발 (てしまう) | 아쉬움·실수의 뉘앙스가 꼭 필요할 때만. 아니면 그냥 「~했다」 | 착각해 버릴 것 같다 → 착각할 것 같다 |
| 「~인 것이다/~라는 거다」 (のだ) | 대부분 빼고 평서문으로. 강조가 필요할 때만 「~거든」, 「~란 말이다」 | 될 것이다 → 되겠지 |
| 「아무래도 ~인 모양이다」 (どうやら～らしい) | 한 문장에 하나만. 「~인가 보다」, 「~나 보다」로 짧게 | 아무래도 볼일이 있는 모양이다 → 나한테 볼일이 있나 보다 |
| 「~의 ~의 ~의」 이어 붙이기 (の) | 「의」를 빼거나 문장을 풀어 쓴다 | 카라사와 가문의 부의 상징 → 카라사와 가문이 가진 부의 상징 |
| 「~해 주다/~해 주시다」 과잉 (てくれる/くださる) | 고마움·호의가 실제로 있을 때만 | 설명해 주었다 → 설명했다 |
| 「…… 하고」 인용 (と) | 인용이 길면 「~라고」, 「~냐며」로 풀거나 문장을 나눈다 | |
| 「역시」 남발 (やはり/さすが) | 「역시」는 예상이 맞았을 때만. 「さすが」는 「과연/역시 ~답다」 | 역시 카라사와 가문의 아가씨 → 과연 카라사와 가문 아가씨답네요 |
| 일본식 감탄·맞장구 그대로 (え？, はぁ, まぁ) | 한국어 감탄사로: 「응?」, 「하아……」, 「뭐」 — 상황에 맞게 | |
| 번역체 존댓말 (ございます 직역) | 인물 말투에 맞는 자연스러운 존댓말 | |

**그 밖의 규칙**
- **문장 부호**: 원문의 「……」(말줄임)는 살리되 과하면 줄여도 된다. 대사의 「」·（）는 쓰지 않는다(게임에 넣을 때 자동으로 붙음). 강조 괄호 【】·인용 『』는 원문대로.
- **의성어·의태어**: 한국어 의성어로 바꾼다(もぐもぐ → 우물우물, スンスン → 킁킁, ゴクッ → 꿀꺽, プリプリ → 씰룩씰룩).
- **일본 고유 문화어**: 한국 독자가 알 만한 건 그대로(우메보시), 모를 만한 건 풀어 쓴다. 속담·관용구는 같은 뜻의 한국 속담이 있으면 그걸 쓴다(坊主憎けりゃ袈裟まで憎い → 「며느리가 미우면 발뒤꿈치도 밉다」, stage01 `#48665` 에 적용).
- **성인 장면**: 원문의 강도를 그대로 옮긴다 — 순화하지도, 더 노골적으로 덧붙이지도 않는다. 신음·숨소리는 한국어 표기로 자연스럽게(일본어 음을 그대로 옮기지 않는다). 성기 표현은 일관되게: ペニス → 페니스, 肉棒 → 육봉, マンコ/オマンコ → 보지, 精液 → 정액, 射精 → 사정/싸다(속마음).
- **화자 말투**는 위 「말투」 항목을 따르고, 한 씬 안에서 같은 인물의 말투·호칭이 흔들리지 않게 한다.
- **초벌 손질 (2026-11-26 완료)**: stage01·stage02 를 이 기준으로 손질 — 59줄 수정(「그녀」 13→0, 「아무래도/모양이다」 6→0, 「~것이다/거다」 5→1, 「~버리다」 12→6, 「~해 주다」 6→4). 남은 「버리다」·「해 주다」는 「들켜 버렸다」, 「죽어 주지 않으려나」처럼 구어로 자연스러워서 일부러 둔 것. 「꼬붕」(子分에서 온 말) → 「딸랑이」.
