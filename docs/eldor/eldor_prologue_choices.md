# 엘도르 연대기 프롤로그 — 선택지 설계표

**버전:** v0.1 초안 / 2026-11-24
**기준 원고:** `eldor_prologue_rev.txt` (프롤로그 수정본)
**목적:** 스크립트 초안을 쓰기 전에, 프롤로그에서 **어디서 무엇을 고르는지**와 **그 흔적이 어디에 남는지**를 먼저 정한다.

> **표시** — ★ 원고 경로(지금 원고가 따라가는 선택) · [제안] 초안, 바꿔도 됨

---

## 설계 원칙 (프롤로그 = 프롤로그)

1. **결말은 하나로 모인다.** 어떤 선택을 해도 프롤로그는 "봉인을 다시 닫고, 반지는 부서지고, 브룩타운으로 돌아온다"로 끝난다.
2. **선택은 흔적으로 남는다.** 부상, 로크의 신뢰, 얻은 단서, 반지의 후유증, 보고 내용 — 대사와 1막의 조건으로 회수한다.
3. **정답 선택지는 없다.** 얻는 것이 있으면 잃는 것도 있다.
4. **평판 시스템은 없다.** NPC 반응(동정·조롱 등)은 고정 연출. 조롱에 대응하는 선택지도 두지 않는다.
5. **레테는 프롤로그에 등장하지 않는다.** 프롤로그는 베르트랑 혼자의 튜토리얼. 레테는 1막부터.
6. **원고 경로(★)를 하나씩 둔다.** 원고 문장을 최대한 살리고, 다른 선택지는 짧게 새로 쓴다.

## 프롤로그 흐름과 선택 지점

```
[프롤로그] ─ 고정
   │
[1장 브룩타운] ── ① 조사 순서·로크와의 약속
   │
   ├─ [여관: 마을 남자의 조롱] ─ 고정
   │
[1장 숲길] ── ② 갈림길에서 발자국을 살피는가
   │
[1장 던전 입구] ── ③ 오크를 어떻게 처리하는가
   │                 (오른쪽 문 함정 조사 ─ 고정)
[2장 제단] ── ④ 서약 반지를 끼는가 ── ⓗ 잠긴 철함 (로크 히든 스킬)
   │
[3장 봉인의 틈] ── ⑤ 봉인문 앞에서 무엇을 하는가 (프롤로그 핵심)
   │
[4장 결사의 봉인] ─ 고정 (모든 경로 합류: 반지의 힘 → 재봉인 → 반지 파손)
   │
[5장 무너지는 던전 · 귀환] ── ⑥ 브람에게 무엇을 말하는가
   │
[프롤로그 끝] ─ 고정
```

## ① 브룩타운 조사 — 조사 튜토리얼

**위치:** 1장 광장 / **성격:** 튜토리얼 (분기 없음)

| 조사 대상 | 얻는 단서 | 비고 |
|---|---|---|
| 브람 (광장) | 흑룡의 사도와 북쪽 던전 전설 | 동정 반응 (고정) |
| 마르타 (여관 앞) | 녹색 눈빛, 밤의 울음소리 | |
| 로크 | 거대한 그림자와 날개, 큰 발자국 | 동행 제안으로 이어짐 |

- 순서는 자유. **세 사람 모두에게 들어야** 로크의 동행 제안이 나온다.
- **날개 증언**은 5장 "그럼 날아간 그림자는 무엇이었나"로 회수된다.

### ①-2 로크의 조건 — "제 동생을 찾아 주세요"

| 선택지 | 결과 | 변수 |
|---|---|---|
| ★ "찾을 수 있는 데까지 함께 찾겠다. 약속하지." | 원고 그대로 | `rock_trust` +1 |
| "보장은 못 한다. 하지만 던전에서 단서가 나오면 네게 먼저 알리겠다." | 로크가 잠시 실망하지만 정직함을 받아들인다 | `rock_trust` 0, `promise_made` = false |

**회수:** 5장 광장 대화("네 동생을 찾겠다는 약속은 변하지 않았어")가 `promise_made`에 따라 달라진다 — false면 "이번엔 약속하지"로 바뀌며 이때 처음 약속한다.

## ② 숲의 갈림길 — 추적

**위치:** 1장 숲길 / **성격:** 조사 → 전투 난이도

| 선택지 | 결과 | 변수 |
|---|---|---|
| 발자국을 살핀다 | 로크와 함께 흔적을 읽어 **늑대가 세 마리**이고 피를 흘리는 먹이를 끌고 갔다는 것을 안다 → 매복 위치를 먼저 잡아 부상 없이 이긴다 | `wound` 0 |
| ★ 로크의 말대로 곧장 왼쪽 길로 간다 | 원고 그대로. 늑대가 먼저 덮친다 — **허벅지 상처** | `wound` +1 |

**회수:** `wound`는 5장 탈출(걸음 속도·로크의 부축 대사)과 귀환 후 치료 장면에 반영.
**어두운 톤 [제안]:** "발자국을 살핀다"를 고르면 끌려간 먹이의 흔적 속에서 **사람의 천 조각**을 발견 — 미카의 운명을 암시하는 단서(`mika_cloth` = true).

## ③ 던전 입구의 오크 — 전투를 줄이는 선택

**위치:** 1장 던전 입구 / **성격:** 전투 방식

| 선택지 | 결과 | 변수 |
|---|---|---|
| ★ 숲의 그늘을 이용해 기습한다 | 원고 그대로. 짧은 전투 | — |
| 로크에게 유인을 맡긴다 | 로크가 화살로 오크를 숲 쪽으로 끌어내고, 그 사이 문 앞을 조사한다. 전투 없이 넘어가지만 로크가 팔을 다친다 | `rock_wound` +1, `rock_trust` +1 (믿고 맡겼으므로) |

- **두 경로 모두 오크 목걸이(그림자 연합 문양)를 얻는다** — 유인 경로에서는 오크가 도망치다 나뭇가지에 걸려 떨어뜨린다. `shadow_evidence` +1 (고정).
- 이후 **오른쪽 문 함정 해제**는 고정 연출(조사 네 곳 → 부적 사용).

## ④ 용혈의 서약 반지 — 힘과 대가

**위치:** 2장 제단 (상자를 연 직후) / **성격:** 위험 감수

상자는 반드시 베르트랑 자신의 피로 연다(고정). 선택은 그 뒤.

| 선택지 | 결과 | 변수 |
|---|---|---|
| ★ 끼지 않고 보관한다 | 원고 그대로. 해골 기사의 약점을 관찰해 이긴다 — 로크와의 협공 | — |
| 손가락에 낀다 | 반지의 힘으로 해골 기사를 단숨에 베지만, 손끝이 차갑게 죽어 간다. 로크가 불안한 눈으로 본다 | `dragon_mark` +1, `rock_trust` −1 |

**회수:** `dragon_mark`는 4장 반지의 힘을 끌어낼 때의 묘사(이미 한 번 피를 빨린 손), 5장 손가락의 그을음, 1막 왕실 마법사의 진찰로 이어진다.

## ⓗ 잠긴 철함 — 로크의 히든 스킬

**위치:** 2장 해골 기사 전투 뒤, 제단 아래 / **성격:** 히든 스킬 해방(대화 선택) — 동료 스킬 시스템의 튜토리얼

| 선택지 | 결과 | 변수 |
|---|---|---|
| ★ 검 자루로 자물쇠를 부순다 | 두루마리 한쪽 귀퉁이가 찢어진다 | — |
| "로크, 다른 방법이 있나?" | 로크가 쇠꼬챙이로 자물쇠를 딴다 → **히든 스킬 '자물쇠 따기' 해방.** 두루마리가 온전해서 끝자락의 **B로 시작하는 번호 목록**을 읽는다 | `rock_lockpick` = true, `b13_clue` +1 |

**놓쳤을 때:** 1막 왕국 도서관 도난 사건에서 잠긴 서랍을 볼 때 다시 해방 기회가 있다 [제안].

## ⑤ 봉인문 앞 — 프롤로그 핵심 선택

**위치:** 3장 끝 / **상황:** 사도는 상처를 입었지만 의식은 계속되고, 문틈에서 검은 안개가 짙어진다. 문 너머 황금빛 눈. 머릿속의 목소리 — "문을 열어라. 그러면 네게 더 큰 힘을 주겠다."

| 선택지 | 결과 | 변수 |
|---|---|---|
| ★ 부적과 반지를 봉인문에 댄다 | 원고 그대로. "열쇠를 가진 자만이 닫을 수 있다"고 믿었지만 **문이 열려 버린다** — 문을 연 것은 그의 손. 4장으로 | `opened_door` = true |
| 사도를 먼저 쓰러뜨린다 | 로크와 함께 사도를 몰아붙이지만, 쓰러지는 사도가 베르트랑의 피 묻은 창끝을 문에 박는다 → 문이 열린다. **로크가 사도의 마지막 일격에 크게 다친다(어깨 화상).** 4장으로 | `opened_door` = false, `rock_wound` +2 |
| 목소리에 대답한다 | "왜 나를 부르지?" — 바르카스와 짧은 문답. 용의 말 속에서 단서를 얻는다: **"나를 묶은 사슬은 하나가 아니다."** 그사이 균열이 더 깊어지고, 사도가 문을 연다. 로크는 대화하는 베르트랑을 본다. 4장으로 | `barkas_whisper` = true, `rock_trust` −1, `seal_crack` +1 |

**모든 경로가 4장에서 합류:** 베르트랑이 반지를 손가락에 끼고 힘을 끌어내 흑룡의 눈을 찌르고 → 봉인이 닫히고 → 반지가 부서진다. 이 과정에서 `dragon_mark` +1 (고정).

**회수**
- `opened_door` — 4장 바르카스의 대사("네 피로 나를 깨우고") 강도, 5장 혼자 남은 밤의 자책, 1막에서 자기 잘못을 말할지.
- `barkas_whisper` — 5장 날아간 그림자 대화에서 베르트랑이 먼저 "봉인된 것이 하나가 아닐지도 모릅니다"라고 말할 수 있다. 1막 봉인 유적 조사에서 단서 하나를 이미 안다.
- `seal_crack` — 5장 심장 박동 묘사의 강도, 1막 이후 봉인 관련 사건의 시기.

## ⑥ 브람에게 하는 보고 — 진실을 어디까지

**위치:** 5장 브람과의 대화 / **원고 근거:** "그는 거짓으로 안심시키고 싶지 않았다… 그러나 진실을 전부 말한다고 해서 그들에게 도움이 될지도 알 수 없었다."

| 선택지 | 결과 | 변수 |
|---|---|---|
| 전부 말한다 — 문을 연 것이 자기 손이었다는 것까지 | 브람은 오래 침묵한 뒤 "그걸 말해 준 사람은 당신이 처음이오"라고 한다. 밀랍 보고서에 그대로 적힌다. 마을 몇 가구가 남쪽으로 떠난다 | `report` = full |
| ★ 균열이 남았다는 것까지 말한다 | 원고 그대로. "우리는 재앙을 없앤 게 아닙니다. 다만 시간을 벌었을 뿐입니다." | `report` = crack |
| 끝났다고 안심시킨다 | 마을은 그날 밤 문을 열어 두고 웃는다. 베르트랑만 잠들지 못한다. 보고서에는 "사도 소멸, 위협 제거"라고 적힌다. 진실을 아는 로크는 입을 다문다 | `report` = calm, `rock_trust` −1 |

- `opened_door` = false면 "전부 말한다"에서 문을 연 고백 부분이 빠진다 (사도가 열었으므로).

**회수:** 1막 왕 앞 보고. 브람의 보고서가 먼저 도착해 있다.
- `full` — 왕궁은 위협을 심각하게 받아들이지만, 베르트랑이 문을 열었다는 사실이 그를 겨누는 무기가 된다.
- `crack` — 원고 2부 그대로의 흐름.
- `calm` — 왕궁이 위협을 가볍게 여겨 조사가 늦어진다. 베르트랑이 직접 진실을 말하면 "변방 보고와 다르다"며 의심받는다.

## 프롤로그 변수 요약

| 변수 | 범위 | 바뀌는 곳 | 주로 회수되는 곳 |
|---|---|---|---|
| `rock_trust` | −3 ~ +3 | ①-2, ③, ④, ⑤, ⑥, 5장 늦은 약속 | 5장 대화, 1막 로크 동행·비밀 |
| `promise_made` | true / false | ①-2 (false면 5장에서 늦게 약속) | 5장 광장 대화 |
| `wound` | 0 / 1 | ② | 5장 탈출·치료 |
| `rock_wound` | 0 ~ 3 | ③(+1), ⑤-2(+2) | 5장 탈출, 1막 초반 로크 상태 (2 이상 = 한동안 활 못 씀) |
| `ring_worn` | true / false | ④ (4장에서 모두 true) | 2·3장 대사, 4장 묘사 |
| `b13_clue` | 0 / 1 | ⓗ (B 번호 목록) | 1막 B-13 조사 |
| `mika_cloth` | true / false | ② (천 조각) | 프롤로그 5장 대사, 1막 로크의 고백·레테의 기억 읽기 |
| `rock_lockpick` | true / false | ⓗ (놓치면 1막에 다시 기회) | 로크 히든 스킬 '자물쇠 따기' |
| `shadow_evidence` | 1 (고정) | ③ | 1막 8장 그림자 연합 문양 |
| `dragon_mark` | 1 ~ 2 | ④, 4장(고정) | 5장 손가락, 1막 진찰 |
| `opened_door` | true / false | ⑤ | 4·5장 자책, ⑥, 1막 |
| `barkas_whisper` | true / false | ⑤ | 5장, 1막 봉인 조사 |
| `seal_crack` | 0 / 1 | ⑤ | 5장 묘사, 이후 봉인 사건 |
| `report` | full / crack / calm | ⑥ | 1막 왕 앞 보고 |

기획서의 변수 목록(`rock_trust`, `dragon_mark`, `b13_clue`, `shadow_evidence`)에 프롤로그 전용 변수가 더해졌다. 프롤로그 변수가 많아 보이지만 대부분 **참/거짓 하나로 대사 한두 줄을 바꾸는 용도**다.

## 전투 정리

| 전투 | 처리 |
|---|---|
| 늑대 | ②의 선택에 따라 매복(부상 없음) / 선제공격당함(부상) |
| 오크 | ③에서 기습 또는 생략(유인) |
| 해골 기사 | ④에서 약점 관찰 협공 / 반지로 단숨에 |
| 흑룡의 사도 | ⑤의 선택에 따라 형태가 달라짐 |

전투 자체는 "준비·약점·동료" 중심의 선택 장면으로 처리하고, 실시간 전투는 없다.
