# 엘도르 연대기 — 시리즈 확장 아이디어 메모

> 까먹기 전에 적어 두는 곳. 확정 아님. 엘도르편(중세)이 먼저다.

---

## 아이디어 1 — 제페토와 피노키오 (2026-11-24)

**작가 메모**
- 피노키오, 〈P의 거짓〉 같은 느낌. 피노키오에서 차용하되 **제페토와 제페토가 만든 피노키오가 주인공.**
- 제페토의 나이를 **청년 수준으로 낮춘다.**
- **시대는 미래.** 피노키오는 **로봇**이다.
- 엘도르(봉인·바르카스 등)와 이어지는 조각은 **나중에 생각한다** [미정].
- **검토 중:** 피노키오를 **여성 쌍둥이 둘**로. 하나는 **무표정·무미건조**, 하나는 **시끄럽고 발랄**.

**쌍둥이안 메모 [제안]**
- **거짓말 모티프를 둘로 나누기:** 무표정한 쪽은 거짓말을 못 한다(혹은 하지 않는다), 발랄한 쪽은 거짓말을 아무렇지 않게 한다 — 코가 자라는 쪽은 누구인가. 진실과 거짓이 한 쌍으로 붙어 다니는 구도.
- **레테와 겹치지 않게:** 무표정·무미건조한 쪽은 레테(담담·건조한 유머)와 결이 겹칠 수 있다. 레테는 '사람의 건조함'(밑에 감정이 있다), 쌍둥이 쪽은 '기계의 평평함'(감정이 있는지조차 모른다)으로 나눈다.
- **흔한 구도 주의:** 무표정+발랄 쌍둥이는 애니메이션·게임에서 자주 쓰이는 조합이다. 차별화 포인트(예: 로봇이라 둘이 기억이나 회로를 공유한다, 한쪽이 먼저 만들어졌다 등)를 하나 두는 게 좋다.
- **인물 수:** 제페토 + 쌍둥이 둘 + 레테 = 주인공급 넷. 쌍둥이를 '한 역할을 나눠 가진 둘'로 묶으면 부담이 줄어든다.

**정리 [제안]**
- **시리즈에서의 자리:** 고대·중세(엘도르)·근대에 이어 **미래편**이 생긴다. 크로노 트리거처럼 시대 폭이 미래까지 넓어진다.
- **주인공 구도:** 청년 제페토(만든 자) + 로봇 피노키오(만들어진 자). 레테는 시리즈 공통 조력자.
- **주제 후보:** 거짓과 진실 — 거짓말을 하면 코가 자라는 피노키오 ↔ 거짓을 읽는 탐정 레테. 로봇이 거짓말을 할 수 있는가, 라는 질문으로 바뀐다.
- **레테의 반전:** 지금까지 레테는 과거 시대에서 '너무 현대적인' 사람이었다. 미래에서는 반대로 **혼자 낡은 사람**이 된다 — 만년필과 성냥을 든 1912년의 여자.

**차용 범위 [주의]**
- 원작 동화 『피노키오의 모험』(콜로디, 1883)은 퍼블릭 도메인 — 인물·모티프 차용 가능.
- 게임 〈P의 거짓〉(2023)은 저작권 있는 작품 — **분위기 참고까지만.** 고유 설정(크라트 시, 인형 광란, 에르고, P-기관, 늙은 제페토가 흑막인 구도, 거짓말 시스템 등)은 가져오지 않는다.
- '청년 제페토', '미래의 로봇 피노키오'는 원작·〈P의 거짓〉 모두와 다른 지점이라 차별화에 좋다.

**검토할 점 [솔직한 의견]**
- 다크 판타지 시리즈에서 SF 미래로 넘어가면 톤과 그림체를 어떻게 이어 갈지가 과제. 크로노 트리거처럼 '시대마다 다른 분위기'로 받아들이게 하거나, 미래도 어둡고 낡은 쪽(황폐한 미래)으로 잡으면 이어진다.
- 레테는 '봉인의 균열을 따라' 시대를 건넌다 — 미래에도 그 균열이 있어야 한다. 엘도르와의 연결 조각을 정할 때 같이 정하면 된다.

**정할 것 [미정]**
- 엘도르와 이어지는 조각
- 제페토와 피노키오의 관계 — 아버지와 아들 / 형제 / 창조자와 피조물의 대립
- 피노키오가 원하는 것 — 사람이 되는 것? 다른 것?
- 레테와의 관계, 그 편에서 밝혀지는 레테의 비밀
